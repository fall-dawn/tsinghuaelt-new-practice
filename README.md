# 清华社英语在线 · 新版自动练习

适配清华社英语在线智慧版 `/course_center/reader/student_course/...` 页面，提供可直接安装的单文件用户脚本。当前脚本版本为 `1.2.2`，配套 VMIC 为 `1.2.9`，兼容脚本猫及 Tampermonkey。


## 快速安装

[一键安装用户脚本](https://raw.githubusercontent.com/fall-dawn/tsinghuaelt-new-practice/refs/heads/main/tsinghuaelt-new.user.js) · [下载完整安装包](https://github.com/fall-dawn/tsinghuaelt-new-practice/releases/latest) · [详细安装教程](安装与使用.md)


1. 在 Edge 中安装脚本猫（ScriptCat）或 Tampermonkey。
2. 点击[一键安装用户脚本](https://raw.githubusercontent.com/fall-dawn/tsinghuaelt-new-practice/refs/heads/main/tsinghuaelt-new.user.js)，或打开[用户脚本文件](tsinghuaelt-new.user.js)并点击 GitHub 的 **Raw** 按钮；脚本管理器出现安装页时点击安装。若没有出现安装页，复制全文到脚本猫的新建脚本中，按 Ctrl+S 保存。
3. 刷新清华社英语在线页面，登录后从目录进入新版具体章节，确认右下角面板显示 **v1.2.2**。
4. 选择处理范围，点击“开始自动练习”。已有用户应更新原脚本，避免同时启用多份。

需要示范音频输入时，还要单独加载 **VMIC 1.2.9**：点击仓库 **Code → Download ZIP**，解压到固定目录；在 Edge 打开 `edge://extensions`，开启开发人员模式，选择“加载解压缩的扩展”，选中直接包含 manifest.json 的 `vmic-extension` 文件夹。更新扩展后需要点“重新加载”并刷新课程页。

完整步骤、主观题设置和录音排错见[安装与使用](安装与使用.md)。主脚本采用 GPL-3.0-only，VMIC 目录保留原作者 MIT 许可证，来源见[改动与许可说明](THIRD_PARTY_NOTICES.md)。

### Role Play 限制

Role Play 由网站先选择角色、倒计时，再逐句播放另一角色的台词并采集所选角色的录音。当前 VMIC 只载入一段音频，**没有实现按角色和台词自动匹配、切换音频**；每次录音会重播同一段，不能将整段对话载入后直接完成。自行朗读时先停用 VMIC、刷新页面，再选角色并点击 Start。没有对应示范音频的自由口语也需要自行录音。

公开仓库只包含源码、安装说明、测试及上游许可；个人处理报告、课程链接、录音和登录凭据不在发布内容中。测试中的大整数课程 ID 为合成数据。

## 1.2.2 / VMIC 1.2.9 修复录音时序

旧版在获取麦克风或创建 WebSocket 时播放一次性示范音频，而这些初始化操作可能早于网站实际开始采集；网站复用录音器时，重试也可能没有重新播放。1.2.9 接入网站当前使用的 `Html5Recorder.record({onStart})`，在实际录音开始、音频上下文恢复后延迟 150 ms 从头送入；每次重录单独触发，送完保留 300 ms 尾部缓冲。此回调的语义见[驰声 6.x 官方文档](https://www.chivox.com/en/docs/sdkDoc/JS-sdk)。

换音频或切题只停止示范音源、清除缓冲，保留网站缓存的虚拟音轨；显式停用时关闭所有虚拟音轨。获取麦克风返回独立克隆音轨，网站的权限探测不会停止录音器使用的轨道。无有效音频时仍拒绝开始录音。

脚本面板自动显示等待采集、剩余时长、尾部缓冲、已送完及提前停止。**这次需要更新 VMIC 扩展并重新加载、刷新课程页**；只更新脚本不能修复旧扩展的播放时机。脚本 1.2.2 提供状态显示，扩展 1.2.9 的录音时序修复也兼容原脚本。57 项离线测试通过，尚未在用户账号上验证实际评分。

## 1.2.1 修复“缺少题组绑定信息”

1.2.0 把队列用的 `章节ID/内容ID` 传给 VMIC，而配套扩展 1.2.7 只接受 `章节ID:内容ID`，导致有效题组被拒绝。1.2.1 使用独立的 VMIC 绑定函数统一发送冒号格式，保留大整数 ID 精度。音频扫描和载入两处同步修复。

配套 VMIC 更新为 1.2.8，同时接受旧脚本的斜线格式，并统一返回冒号格式；空值、零 ID 和错误格式继续拒绝。旧格式音频扫描也按实际内容 ID 过滤，避免混入其他已挂载题组的示范音频。

**更新任一端即可消除这次格式错误**：新脚本 1.2.1 兼容原配套扩展 1.2.7，新扩展 1.2.8 兼容原脚本 1.2.0。更新脚本后刷新课程页；更新已加载的本地扩展后，在 `edge://extensions` 点“重新加载”，再刷新课程页。重新扫描并载入音频。

新增从实际面板“扫描 → 选择 → 载入”到实际扩展解码的完整回归测试，覆盖正常及超出安全整数范围的章节/内容 ID，不再仅用手写协议参数测试接收端。

## 1.2.0 简答题、S/C 表格与 VMIC 适配

- 新增简答题、写作及翻译的 `{answer, annex}` 编码；主观填空继续使用真实空位 ID。平台提供可用标准答案时可直接回填；已有主观填空作答不再因数组结构被漏掉。
- 支持导入本组答案 JSON，或在面板中配置兼容 chat/completions 的 HTTPS 接口，启用 AI 自动作答。AI 默认关闭；API Key 仅保存在当前页面内存，不写入设置、报告或续跑状态。跨域权限取决于所配置服务。
- 组合题保留父题说明、材料和 `attachmentList[].script` 听力原文，避免把缺少听力背景的孤立问句送给 AI。没有原文且无法确定的答案保留待处理。
- 主观题只提交一次相同答案，保存后显示“等待教师或平台评阅”；`answerStatus=-1` 不算全对，也不据此上报完成。
- 截图中的八行 Server/Customer 表格按确切句子与 S/C 标签匹配，答案为 `S C C S C C C S`；按本题真实选项 UUID 编码。新句子继续使用平台标准答案流程，语义答案未获平台认可时停止重复提交。
- 新增“刷新当前题组”以及“导出当前题目诊断”。诊断含该组完整链接、题干、选项、空位 ID、可用听力原文和判分；不含登录令牌、音频文件或口语作答记录。普通处理报告继续只包含运行摘要。
- 配套 `vmic-extension/` 基于用户指定的 [ckckh2023/TsingHuaelt-VMIC](https://github.com/ckckh2023/TsingHuaelt-VMIC)（MIT），当前本地适配版本为 `1.2.9`。它是 Edge 扩展，需要另行加载，不能作为脚本猫脚本安装。
- 脚本面板可扫描当前题组的 `<audio>`，以及扩展捕获的最近三分钟实际播放音频（包括脱离 DOM 的 `new Audio()`）。用户选择对应示范音频后载入，收到解码成功确认，再点击网站麦克风使用正常录音及评分流程。
- 没有有效音频时拒绝虚拟录音，避免静音和旧音频；切换题组会清除已载入音频。虚拟麦克风默认停用，载入后关闭噪音、循环、外放和变速。自动播放由驰声录音开始回调触发。

安装和操作详见 [安装与使用.md](安装与使用.md)。这些变化通过离线测试，尚未在用户账号上完成新版录音评分实测。

## 1.1.0 题型与自动切换修复

- 补齐逐行二选一的高级判断题（`judge_advanced`），包括听力中的 Full form / Reduced form 表格：按行保留选项 UUID，支持自动尝试和标准答案回填。支持位置数组及已识别的带位置 ID 数组；不把多行相同选项去重。
- 跟读/口语题明确列为“待录音”，继续后续可处理习题；新增“打开待录音/待处理”，可返回该组由本人录音。已经录音且被服务器判为完成的记录，在混合组重交时原样保留。
- 新增默认启用的“页面跟随”：优先使用阅读器下一页按钮，通过页码和实际内容 ID 判断推进；整章滚动布局可定位到目标习题。
- 目标不在当前页面时，保存本次任务并加载对应章节/内容，加载后继续；保存已核验和待处理结果，不反复尝试跟读题或重复提交已处理组。
- 续跑只在当前标签页生效，绑定当前登录状态、目标页面和 20 分钟有效期；暂停、异常或结束会清除状态。同一目标最多重载两次，未能显示时停止。
- 从当前位置开始处理，不再重做本章当前位置之前的题。跨章节请选择“从当前位置继续，自动处理后续已解锁章节”。

## 安装与使用

1. 在 Chrome 或 Edge 中安装脚本猫（ScriptCat）或 Tampermonkey（油猴）。
2. 打开 `tsinghuaelt-new.user.js`，复制全部内容。
3. 点击脚本管理器图标 → 添加新脚本，替换编辑器中的全部内容，按 `Ctrl+S` 保存；更新时打开原脚本编辑。
4. 关闭同一网站上其他答题脚本，刷新清华社英语在线页面。
5. 登录新版网站，从课程目录打开一个具体章节。右下角会出现“清华社英语 · 新版练习”面板。
6. 选择“当前章节（本章结束后停止）”，或“从当前位置继续，自动处理后续已解锁章节”；勾选“页面跟随”，点击“开始自动练习”。

部分浏览器需要为 Tampermonkey 开启“允许运行用户脚本”权限。若面板不显示，先确认脚本已启用、站点为 `https://www.tsinghuaelt.com/`，并检查油猴的运行权限。

脚本通过新版 API 在当前登录状态下批量处理习题，页面跟随到正在处理的题组，作答和判分通过接口核验。页面已有控件可能保留加载时的状态；完成后点击“打开本组结果”查看服务器保存的最新作答。“打开待录音/待处理”优先定位到需要本人录音的题组。

## 功能与边界

| 功能 | 行为 |
| --- | --- |
| 单选、多选、基础判断 | 使用真实选项 UUID；判断题提交 `0` / `1` |
| 填空、对话填空、图片填空 | 按每个空位 ID 提交 `[{idx, answer}]`；支持标准答案的多个可接受写法 |
| 选词填空 | 题面提供空位 ID、答案采用相同配对结构时处理；其他结构列入待处理 |
| 拖拽匹配、拖拽填空 | 保留目标 ID 与选项 ID；匹配题使用数组，拖拽填空使用单个选项 |
| 逐行二选一/高级判断 | 按 `extension.topic` 行数和 `extension.option` UUID 编码，支持逐行数组、有限尝试取答案、回填和核验 |
| 图片/段落下拉 | 已有标准答案采用 `[{idx, answer}]` 结构时处理；未识别结构保留待处理 |
| 组合题、阅读理解 | 递归展开子题，使用子题 ID 提交 |
| 已有作答 | 保留已答对的题，对服务器下发答案的错误题进行修正 |
| 自动尝试 | 读取课程的 `errorNumShow`，在次数上限内尝试，获取标准答案后回填；无法读取阈值时只处理已有标准答案 |
| 结果核验 | 每次提交后重新取题；只有服务器确认整组全对才记为“已核验”并上报内容完成 |
| 批处理 | 按课程/章节 ID 处理已解锁习题；不依赖翻页后的 URL 变化 |
| 页面跟随与跨页续跑 | 自动定位下一组；跨页后保留本次结果并继续；暂停清除续跑状态 |
| 暂停与异常 | 暂停中止后续请求；登录失效、网络异常或不匹配的数据结构停止运行 |
| 限流 | 请求间隔至少 2 秒；HTTP/业务码 429 或 530 进入 90 秒起的有限退避 |
| 报告 | 导出 JSON，记录已核验、待处理、中断项目和日志，不包含令牌、Cookie 或原始题目数据 |

语音题通过网站录音和评分流程完成，可使用配套 VMIC 送入本题示范音频；本版不自动点击录音/停止按钮，也不伪造评分。没有对应示范音频的口语问答和角色扮演仍需合适的录音。主观题可导入答案或启用 AI，服务器尚未评阅时保持待处理。若同一组含尚未作答的主观题或语音题，整组暂不提交，继续后续组。已有主观作答、服务器判为完成的录音在混合组提交时保留。

音频、视频、附件和阅读材料不作为习题处理；未解锁章节不会越过。若课程要求先完成媒体或主观题才能解锁后续章节，需要先完成相应内容。教材阅读器仅处理已下发标准答案的习题；整门课程批处理以学生课程/公共课程阅读器为主。

自动尝试会产生真实的作答记录。自由模式通常记录最后一次成绩；若在答案回填前暂停、断网或遇到限流，最后一次记录可能仍未答对。恢复网络后再次点击开始，脚本会先读取服务器记录再继续。也可以取消“自动尝试”，仅修正已有标准答案的客观题。

## 设置

- 默认处理当前章节，请求间隔 `2.5` 秒，每组最多 `8` 次提交，“页面跟随”默认启用。
- 每组尝试预算会保留至少一次用于最终标准答案回填。
- 普通打开/刷新页面保持待命；点击“开始”后，由本次任务触发的跨页导航会自动恢复。续跑状态过期、目标页面或登录变化时保持待命。
- 暂停或网络错误时，已发出的请求可能已被服务器接收，脚本不会自动重放结果不确定的写请求。
- 切换到其他课程、退出登录或登录令牌改变会暂停，重新开始后使用新的页面上下文。
- 设置保存在本站本地存储；跨页结果和登录指纹暂存在当前标签页 sessionStorage，不保存令牌、题目内容或录音数据。令牌只在内存中读取并发送给清华社英语官方 API。
